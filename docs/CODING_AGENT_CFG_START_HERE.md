## 仓库是什么

这个公开仓库是**文档交接仓库**，不是已实现的CFG项目。没有模型权重、运行环境、数据或CFG推理实现。不要把文档伪代码或66条计划当成已运行的实验。

先完整阅读实验计划，然后在独立开发目录中实现。不要在未核验的旧环境里直接升级依赖，不修改既有实验、原始数据或共享系统驱动。

## 按顺序做

1. 检查机器、空闲GPU、磁盘、实际CUDA算子及官方模型闭环。使用目标机器的真实可写目录，记录版本、权重哈希和资源。不要假设旧SSH或NFS在新机可用。
2. 实现独立CFG sampler及回归测试。必须验证lambda=0、同条件分支差分为0、相同噪声/时间步/观测、KV隔离、真实观测回灌，以及60步交回后的行为。阶段0不通过，不启动大扫描。
3. 在统一失败现场、统一剩余预算和seed下测试B0–B4。先一个种子的22条；数值稳定且无普遍损害后再扩至计划中的66条。原生实现另做回归，主比较使用统一扩展采样路径。
4. 保存全部成功/失败/运行错误、动作、视频、输入指令、起点身份、分支数、控制步、延迟与显存。原任务谓词是主评分；重抓/摆放等是辅助诊断。
5. 输出修改清单、可复现命令、测试结果、逐分支CSV、资源账目与诚实结论。两个开发场景不支持SOTA或泛化主张；只有阶段1通过，才进入历史敏感数据组。
